# 结构预测与比较

从序列预测三维结构，比较已有结构，评估复合物模型的质量。

[返回功能目录](../README.md)

## 折叠与复合物预测

| 组件 | 主要用途 |
| --- | --- |
| [AlphaFold 3](%E6%8A%98%E5%8F%A0%E4%B8%8E%E5%A4%8D%E5%90%88%E7%89%A9%E9%A2%84%E6%B5%8B/AlphaFold%203/README.md) | 根据组成一个体系的分子实体预测三维结构，可在同一次预测中表示蛋白质、核酸、配体等分子。 |
| [AlphaFold-Multimer](%E6%8A%98%E5%8F%A0%E4%B8%8E%E5%A4%8D%E5%90%88%E7%89%A9%E9%A2%84%E6%B5%8B/AlphaFold-Multimer/README.md) | 扩展 AlphaFold2 的结构预测能力，对多条蛋白链联合建模，估计复合物中亚基的相对位置。 |
| [AlphaFold2](%E6%8A%98%E5%8F%A0%E4%B8%8E%E5%A4%8D%E5%90%88%E7%89%A9%E9%A2%84%E6%B5%8B/AlphaFold2/README.md) | 由蛋白氨基酸序列预测三维折叠，用于给候选序列提供可分析的结构模型。 |
| [Boltz-2](%E6%8A%98%E5%8F%A0%E4%B8%8E%E5%A4%8D%E5%90%88%E7%89%A9%E9%A2%84%E6%B5%8B/Boltz-2/README.md) | 预测分子复合体系的三维结构，并对模型支持的蛋白与配体组合给出结合亲和力相关的预测。 |
| [Chai-1](%E6%8A%98%E5%8F%A0%E4%B8%8E%E5%A4%8D%E5%90%88%E7%89%A9%E9%A2%84%E6%B5%8B/Chai-1/README.md) | 对包含蛋白质、核酸、配体等分子的体系预测复合结构，供结构比较和候选分析使用。 |
| [ColabFold](%E6%8A%98%E5%8F%A0%E4%B8%8E%E5%A4%8D%E5%90%88%E7%89%A9%E9%A2%84%E6%B5%8B/ColabFold/README.md) | 把同源序列检索、序列比对和结构预测后端串接起来。可只调用其比对服务，也可完成结构预测。 |
| [ESMFold](%E6%8A%98%E5%8F%A0%E4%B8%8E%E5%A4%8D%E5%90%88%E7%89%A9%E9%A2%84%E6%B5%8B/ESMFold/README.md) | 将蛋白语言模型的序列表示交给折叠模块，由氨基酸序列推断三维构象。 |
| [OmegaFold](%E6%8A%98%E5%8F%A0%E4%B8%8E%E5%A4%8D%E5%90%88%E7%89%A9%E9%A2%84%E6%B5%8B/OmegaFold/README.md) | 从单条蛋白序列预测其折叠构象，把序列表示转换为三维坐标。 |

## 结构比对与搜索

| [TM-align](%E7%BB%93%E6%9E%84%E6%AF%94%E5%AF%B9%E4%B8%8E%E6%90%9C%E7%B4%A2/TM-align/README.md) | 为两种蛋白三维结构寻找残基对应和空间叠合，以 TM-score 衡量折叠层面的结构相似性。 |
| [TM-score（结构相似性评分）](%E7%BB%93%E6%9E%84%E6%AF%94%E5%AF%B9%E4%B8%8E%E6%90%9C%E7%B4%A2/TM-score%EF%BC%88%E7%BB%93%E6%9E%84%E7%9B%B8%E4%BC%BC%E6%80%A7%E8%AF%84%E5%88%86%EF%BC%89/README.md) | 以长度归一化的距离评分汇总两个结构在空间叠合后的匹配程度，常用于结构相似性和折叠质量评估。 |
| [复合物 RMSD](%E7%BB%93%E6%9E%84%E6%AF%94%E5%AF%B9%E4%B8%8E%E6%90%9C%E7%B4%A2/%E5%A4%8D%E5%90%88%E7%89%A9%20RMSD/README.md) | 用原子坐标的均方根偏差比较两个复合物模型，量化对应原子在三维空间中的平均偏移。 |
