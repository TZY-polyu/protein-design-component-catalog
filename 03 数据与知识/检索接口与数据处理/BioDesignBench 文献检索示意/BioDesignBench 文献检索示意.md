# BioDesignBench 文献检索示意

[数据与知识](../../README.md) / 检索接口与数据处理

## 用途

图1写作 Literature Search / Get Hotspot。补充A.2 的 suggest_hotspots 是计算分析，且容器禁用外网。无法证实二者是同一个文献检索接口。

## 输入、输出与 LLM 参与

- **输入**　与指定对象相关的查询（图1示意）
- **输出**　相关位点信息。文献来源和检索后端未披露。
- **LLM 参与**　未说明（检索后端）

## 结果解读

主文图中的 Literature Search / Get Hotspot 只说明设想的能力。补充目录中的 suggest_hotspots 返回计算结果，两者能否对应同一接口尚未证实。

## 在六篇研究中的用法

该组件记录于 **BioDesignBench**，对应环节为正文架构图示意。
