# ProteinMCP 工作流技能文档

[数据与知识](../../README.md) / 工作流知识与技能

## 用途

复用适应度建模、结合蛋白设计、纳米抗体设计三种流程。

## 输入、输出与 LLM 参与

- **输入**　用途、必需的 MCP 工具、配置项和步骤定义。
- **输出**　可共享、版本化的工作流文档。
- **LLM 参与**　文档本身无需。论文用通用 LLM 解读执行。

## 结果解读

技能文件描述任务所需工具、参数和步骤，由宿主解释后执行。文档可单独阅读，实际运行还需相应工具环境。

## 在六篇研究中的用法

该组件记录于 **ProteinMCP**，对应环节为核心技能定义。三种技能均有案例。
