# arXiv

[数据与知识](../../README.md) / 文献与研究数据

## 用途

按关键词、作者或标识检索预印本，提供方法描述和版本记录，供后续阅读与资料整理。

## 输入、输出与 LLM 参与

- **输入**　关键词、作者名、学科分类、arXiv 标识符或待抓取的记录集合。
- **输出**　题名、作者、摘要、版本信息和可获得的论文 PDF 或源文件。
- **LLM 参与**　数据库检索与文件下载无需 LLM。

## 结果解读

预印本可更新。用于确认首发记录或复查某个组件时，应保留引用的版本。

## 原始来源与 GitHub

- **原始论文或方法出处**　[Ginsparg (1994), First steps towards electronic research communication](<https://doi.org/10.1063/1.4823313>)
- **GitHub 仓库**　[arXiv/arxiv-browse](<https://github.com/arXiv/arxiv-browse>)
- **归属说明**　1991 年创办，1994 年系创办者的早期系统描述，源自其 1992 年来信。仓库为官方浏览网站组件。

## 下载与访问

- [arXiv 批量下载入口](<https://info.arxiv.org/help/bulk_data.html>)　官方指南分别说明元数据及论文文件的取得方式。
- [关联软件源码 ZIP · arXiv/arxiv-browse](<https://github.com/arXiv/arxiv-browse/archive/53ca6ddec994142b4e0bfaca3092252aca7e2a05.zip>)　该仓库的固定快照。
