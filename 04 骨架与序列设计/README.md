# 骨架与序列设计

按设计输入类型查找生成骨架、设计序列和联合建模的工具。

[返回功能目录](../README.md)

## 骨架与序列联合生成

| 组件 | 主要用途 |
| --- | --- |
| [BindCraft](%E9%AA%A8%E6%9E%B6%E4%B8%8E%E5%BA%8F%E5%88%97%E8%81%94%E5%90%88%E7%94%9F%E6%88%90/BindCraft/README.md) | 在一个软件流程中协调蛋白结构和序列模型，计算蛋白结合候选并汇总其预测质量。 |
| [BoltzGen](%E9%AA%A8%E6%9E%B6%E4%B8%8E%E5%BA%8F%E5%88%97%E8%81%94%E5%90%88%E7%94%9F%E6%88%90/BoltzGen/README.md) | 按指定分子背景和约束进行生成式设计，产生待评估的蛋白或肽候选。 |
| [Chroma](%E9%AA%A8%E6%9E%B6%E4%B8%8E%E5%BA%8F%E5%88%97%E8%81%94%E5%90%88%E7%94%9F%E6%88%90/Chroma/README.md) | 在给定长度或其他结构条件下采样蛋白的结构和序列，并以统一的 Protein 对象组织结果。 |

## 骨架与构象生成

| 组件 | 主要用途 |
| --- | --- |
| [RFdiffusion](%E9%AA%A8%E6%9E%B6%E4%B8%8E%E6%9E%84%E8%B1%A1%E7%94%9F%E6%88%90/RFdiffusion/README.md) | 用扩散式生成模型构建蛋白骨架，为后续结构分析或独立序列建模提供候选三维构象。 |
| [RFdiffusion2](%E9%AA%A8%E6%9E%B6%E4%B8%8E%E6%9E%84%E8%B1%A1%E7%94%9F%E6%88%90/RFdiffusion2/README.md) | 按给定的局部原子几何条件生成蛋白结构样本，用来研究几何约束与骨架构象的相容性。 |

## 结构条件序列设计

| 组件 | 主要用途 |
| --- | --- |
| [ESM-IF1](%E7%BB%93%E6%9E%84%E6%9D%A1%E4%BB%B6%E5%BA%8F%E5%88%97%E8%AE%BE%E8%AE%A1/ESM-IF1/README.md) | 根据给定蛋白骨架评估序列和该结构的相容程度，也可以给出符合几何上下文的候选序列。 |
| [LigandMPNN](%E7%BB%93%E6%9E%84%E6%9D%A1%E4%BB%B6%E5%BA%8F%E5%88%97%E8%AE%BE%E8%AE%A1/LigandMPNN/README.md) | 在蛋白逆折叠时把邻近非蛋白原子纳入环境表示，以评估序列与给定蛋白结构及分子上下文是否相容。 |
| [MPNNsol](%E7%BB%93%E6%9E%84%E6%9D%A1%E4%BB%B6%E5%BA%8F%E5%88%97%E8%AE%BE%E8%AE%A1/MPNNsol/README.md) | 使用针对可溶性蛋白数据的 ProteinMPNN 变体，根据给定骨架评估或提出序列。 |
| [ProteinMPNN](%E7%BB%93%E6%9E%84%E6%9D%A1%E4%BB%B6%E5%BA%8F%E5%88%97%E8%AE%BE%E8%AE%A1/ProteinMPNN/README.md) | 根据蛋白质骨架周围的几何环境，估计各位置可以容纳的氨基酸，用于结构条件下的序列建模和候选比较。 |
