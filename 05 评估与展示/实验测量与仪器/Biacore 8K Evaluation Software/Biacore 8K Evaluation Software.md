# Biacore 8K Evaluation Software

[评估与展示](../../README.md) / 实验测量与仪器

## 用途

处理 Biacore 仪器记录的传感曲线，按所选结合模型拟合动力学或亲和力参数。

## 输入、输出与 LLM 参与

- **输入**　原始响应曲线、样品浓度与参照信息，以及所用的拟合模型。
- **输出**　拟合曲线、动力学常数和/或亲和力估计值，附拟合与诊断信息。
- **LLM 参与**　属于实验数据分析软件，不需要通用 LLM。

## 结果解读

结果依赖数据质量和模型假设。Latent-Y 报告使用其 v5.0，下载情况不应与公开的软件手册混同。
