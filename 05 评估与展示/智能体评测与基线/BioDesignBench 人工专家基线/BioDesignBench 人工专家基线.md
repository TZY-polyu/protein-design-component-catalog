# BioDesignBench 人工专家基线

[评估与展示](../../README.md) / 智能体评测与基线

## 用途

提供实际专家的工具选择和评价深度参照。仅有一位实践者。

## 输入、输出与 LLM 参与

- **输入**　同一批任务及研究提供的 MCP 工具集。
- **输出**　专家的提交、分数与调用轨迹。
- **LLM 参与**　否（人工决策）

## 结果解读

分数和调用轨迹来自一名实际操作的专家，可作为本研究的人工参照。该样本不能直接代表专家群体的平均水平。

## 在六篇研究中的用法

该组件记录于 **BioDesignBench**，对应环节为评测基线。
