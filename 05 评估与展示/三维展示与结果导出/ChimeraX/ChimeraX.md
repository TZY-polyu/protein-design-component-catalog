# ChimeraX

[评估与展示](../../README.md) / 三维展示与结果导出

## 用途

加载和叠合分子结构，检查构象差异并输出结构图。MAESD 使用 ChimeraX 展示候选结构的比较结果。

## 输入、输出与 LLM 参与

- **输入**　PDB 或 mmCIF 的坐标、待显示的链或残基以及结构比对数据。
- **输出**　可交互三维视图、图像、会话文件，以及所选结构分析的数值结果。
- **LLM 参与**　图形渲染和结构操作不需要 LLM。

## 结果解读

叠合图用于观察空间差异，显示样式与选择的对齐区域都会影响直观印象。报告特定版本时应同其原始软件论文区分。

## 在六篇研究中的用法

- **MAESD**（仅离线展示）　展示不同方法的结构预测结果。
