## 如何判断能否接入

- **源码与下载**　“实现入口”指向提供所述功能的代码。源码包和模型权重分开标注，获取数据、申请授权或接入外部服务的条件写在组件页。
- **原始来源**　有方法论文的组件指向提出该方法的原文。以软件发行的组件给出项目自身的发布来源。经典算法会同时标明方法出处和可调用的具体实现。
- **模型依赖**　组件页区分通用对话 LLM、专用蛋白语言模型以及普通数值算法。运行条件按公开源码和作者文档整理。
- **验证范围**　标有“最小运行核验”的组件已在本次整理中用小样例运行。其余条目核查了公开实现和获取入口，尚未在同一环境逐项安装运行。
