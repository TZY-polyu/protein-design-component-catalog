# 序列检索与注释

查找同源序列、建立多序列比对，或给残基和结构域加上注释。

[返回功能目录](../README.md)

## 同源检索与多序列比对

| 组件 | 主要用途 |
| --- | --- |
| [BLAST](%E5%90%8C%E6%BA%90%E6%A3%80%E7%B4%A2%E4%B8%8E%E5%A4%9A%E5%BA%8F%E5%88%97%E6%AF%94%E5%AF%B9/BLAST/README.md) | 将查询序列与数据库序列进行局部相似性搜索。BLASTP 是其中用于蛋白序列之间比较的程序。 |
| [ColabFold MSA MCP](%E5%90%8C%E6%BA%90%E6%A3%80%E7%B4%A2%E4%B8%8E%E5%A4%9A%E5%BA%8F%E5%88%97%E6%AF%94%E5%AF%B9/ColabFold%20MSA%20MCP/README.md) | 向 ColabFold 的公共序列检索服务提交蛋白质序列，把返回的同源序列比对保存为本地文件，便于交给需要多序列比对的工具。 |
| [MMseqs2](%E5%90%8C%E6%BA%90%E6%A3%80%E7%B4%A2%E4%B8%8E%E5%A4%9A%E5%BA%8F%E5%88%97%E6%AF%94%E5%AF%B9/MMseqs2/README.md) | 从大型序列库中搜索相似条目，也能对序列聚类，为同源分析或多序列比对提供候选。 |

## 序列编号与功能注释

| 组件 | 主要用途 |
| --- | --- |
| [ANARCI](%E5%BA%8F%E5%88%97%E7%BC%96%E5%8F%B7%E4%B8%8E%E5%8A%9F%E8%83%BD%E6%B3%A8%E9%87%8A/ANARCI/README.md) | 识别免疫受体可变区，把残基映射到指定编号体系，使不同长度或有插入的序列可按相应位置比较。 |
| [InterProScan](%E5%BA%8F%E5%88%97%E7%BC%96%E5%8F%B7%E4%B8%8E%E5%8A%9F%E8%83%BD%E6%B3%A8%E9%87%8A/InterProScan/README.md) | 将蛋白序列与成员数据库的签名和统计模型匹配，找出可能的家族、结构域和功能位点。 |
