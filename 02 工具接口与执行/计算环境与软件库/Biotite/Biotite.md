# Biotite

[工具接口与执行](../../README.md) / 计算环境与软件库

## 用途

为 Python 提供蛋白序列、分子结构和文件格式处理功能，可支持结构数据读写、选择与几何分析。

## 输入、输出与 LLM 参与

- **输入**　序列、坐标文件，或已载入的原子数组及分析条件。
- **输出**　序列对象、原子数组、结构或比对分析结果及导出文件。
- **LLM 参与**　数据读写和数值运算无需通用 LLM。

## 结果解读

Biotite 是可组合的软件库。论文仅列出工具名称时，无法将其所有功能都算作实际采用的分析步骤。

## 在六篇研究中的用法

- **Latent-Y**（平台可用／生物信息计算）　提供 Python 生物信息分析能力。未公布各次计算与库函数的对应。
