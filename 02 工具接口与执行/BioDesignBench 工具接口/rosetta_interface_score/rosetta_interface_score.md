# rosetta_interface_score

[工具接口与执行](../../README.md) / BioDesignBench 工具接口

## 用途

通过 PyRosetta 将复合物界面贡献分解为可比较的能量与结构指标。

## 输入、输出与 LLM 参与

- **输入**　复合物结构及用于界定相互作用双方的链标识。
- **输出**　界面评分、能量分项及适用的逐残基贡献。
- **LLM 参与**　科学计算本身无需通用 LLM。论文中的上层智能体可通过 MCP 请求该计算并解释返回结果。

## 结果解读

分数使用 Rosetta 的能量模型与内部尺度，不能直接当作实测结合自由能。

## 在六篇研究中的用法

- **BioDesignBench**　表 S1 原子工具，两种模式均可用。
