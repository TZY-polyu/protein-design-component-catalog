# Hugging Face Spaces

[工具接口与执行](../../README.md) / 托管与在线服务

## 用途

托管可交互的机器学习应用、演示和网页工具。BioDesignBench 的排行榜使用 Spaces 作为发布载体。

## 输入、输出与 LLM 参与

- **输入**　Space 所含的前端或服务代码、依赖和运行配置。浏览时接收用户请求。
- **输出**　可公开或限制访问的应用页面，以及托管服务返回的展示结果。
- **LLM 参与**　托管服务无需 LLM。应用内部是否调用 LLM 取决于具体项目。

## 结果解读

托管平台、排行榜前端和产生排行榜数据的评测框架分别有不同的发布边界。
