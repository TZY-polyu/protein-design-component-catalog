# Latent Labs 平台浏览器入口

[工具接口与执行](../../README.md) / 用户与服务入口

## 用途

研究者提交任务、检查结果和调整方向。

## 输入、输出与 LLM 参与

- **输入**　用户目标、结构化工作计划或论文附件。
- **输出**　任务会话、带注释的结果、结构视图。
- **LLM 参与**　界面本身否。对话由上层 LLM 完成。

## 结果解读

平台允许用户查看任务会话、结构和说明并反馈。论文的浏览器平台与其内部模型分别发布访问资料。

## 在六篇研究中的用法

该组件记录于 **Latent-Y**，对应环节为在线交互／展示。
