# ProteinMCP 技能管理器（pskill）

[工具接口与执行](../../README.md) / 工作流与执行管理

## 用途

管理 Markdown 科学工作流。

## 输入、输出与 LLM 参与

- **输入**　工作流定义、管理请求。
- **输出**　已创建或管理的技能。
- **LLM 参与**　管理接口的独立 LLM 依赖未说明。

## 结果解读

它管理可复用的工作流定义。科学计算运行时还需要相应的 MCP 服务器和后端软件。

## 在六篇研究中的用法

该组件记录于 **ProteinMCP**，对应环节为工具与技能管理。
