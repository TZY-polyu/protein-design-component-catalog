# Latent-X2

[科学模型与计算](../../README.md) / 序列与结构生成

## 用途

作为专用分子生成后端，根据研究任务给出的生物分子上下文，提出候选序列与结构。Latent-Y 在计算工作流中调用这一后端。

## 输入、输出与 LLM 参与

- **输入**　研究对象的分子表示、设计任务描述和结构条件。可接受的具体字段以平台接口为准。
- **输出**　一个或多个候选生物分子设计及其序列、结构表征，供后续计算评估。
- **LLM 参与**　执行生成的是专用科学模型。通用 LLM 可在外层规划和发起调用。

原始研究披露的是模型与实验研究结果。模型内部实现和参数未随本文公开，平台功能也不能等同于本地可下载权重。

## 在六篇研究中的用法
