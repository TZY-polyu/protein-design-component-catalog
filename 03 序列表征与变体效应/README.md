# 序列表征与变体效应

把序列转为数值表征，估计残基替换的影响，或拟合实测适应度。

[返回功能目录](../README.md)

## 蛋白语言模型与嵌入

| 组件 | 主要用途 |
| --- | --- |
| [ESM-2](%E8%9B%8B%E7%99%BD%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%B5%8C%E5%85%A5/ESM-2/README.md) | 将蛋白序列编码为上下文相关表示，用于下游回归、变体打分等任务。ESMFold 使用这一类表示支持结构预测。 |
| [OmegaPLM](%E8%9B%8B%E7%99%BD%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%B5%8C%E5%85%A5/OmegaPLM/README.md) | 作为 OmegaFold 的蛋白语言模型子模块，学习序列上下文并为后续折叠网络提供表示。 |
| [ProtAlbert](%E8%9B%8B%E7%99%BD%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%B5%8C%E5%85%A5/ProtAlbert/README.md) | 用针对蛋白质序列预训练的 ALBERT 模型提取每个残基在全序列上下文中的特征。 |
| [ProtT5-XL](%E8%9B%8B%E7%99%BD%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%B5%8C%E5%85%A5/ProtT5-XL/README.md) | 将氨基酸序列编码为带有上下文信息的逐残基向量，用作结构特征预测、分类或回归等下游任务的输入。 |

## 进化约束与变体效应

| 组件 | 主要用途 |
| --- | --- |
| [ESM-1v](%E8%BF%9B%E5%8C%96%E7%BA%A6%E6%9D%9F%E4%B8%8E%E5%8F%98%E4%BD%93%E6%95%88%E5%BA%94/ESM-1v/README.md) | 用只在序列上预训练的蛋白语言模型比较不同氨基酸在同一位置上的相对相容性，为变体效应评估提供序列证据。 |
| [EV+OneHot](%E8%BF%9B%E5%8C%96%E7%BA%A6%E6%9D%9F%E4%B8%8E%E5%8F%98%E4%BD%93%E6%95%88%E5%BA%94/EV%2BOneHot/README.md) | 将序列的独热编码与进化耦合模型给出的分数结合，用带有实测标签的变体训练监督回归器。 |
| [PLMC](%E8%BF%9B%E5%8C%96%E7%BA%A6%E6%9D%9F%E4%B8%8E%E5%8F%98%E4%BD%93%E6%95%88%E5%BA%94/PLMC/README.md) | 从蛋白家族的多序列比对估计位点偏好以及位点间统计耦合，用于比较序列在家族模型下的相容性。 |
