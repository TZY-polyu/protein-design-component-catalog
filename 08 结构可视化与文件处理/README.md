# 结构可视化与文件处理

读取分子文件、操作序列与坐标，在桌面或浏览器中显示结构。

[返回功能目录](../README.md)

## 结构可视化

| 组件 | 主要用途 |
| --- | --- |
| [3Dmol.js / py3Dmol](%E7%BB%93%E6%9E%84%E5%8F%AF%E8%A7%86%E5%8C%96/3Dmol.js%20%EF%BC%8F%20py3Dmol/README.md) | 把蛋白质三维坐标绘成可旋转的分子视图。3Dmol.js 用于网页，py3Dmol 将同一渲染器嵌入 Python 笔记本。 |
| [ChimeraX](%E7%BB%93%E6%9E%84%E5%8F%AF%E8%A7%86%E5%8C%96/ChimeraX/README.md) | 显示、叠合和比较生物大分子三维结构。可用它检查局部构象、链间相对位置或实验密度与模型的对应关系。 |
| [PyMOL MCP](%E7%BB%93%E6%9E%84%E5%8F%AF%E8%A7%86%E5%8C%96/PyMOL%20MCP/README.md) | 将本机 PyMOL 的显示、选区和测量操作提供给 MCP 客户端，供脚本或交互式助手控制分子视图。 |
| [PyMOL（开源版）](%E7%BB%93%E6%9E%84%E5%8F%AF%E8%A7%86%E5%8C%96/PyMOL%EF%BC%88%E5%BC%80%E6%BA%90%E7%89%88%EF%BC%89/README.md) | 把三维分子坐标呈现为可旋转的结构图，可突出链、残基或界面并导出插图。 |

## 序列与结构文件处理

| 组件 | 主要用途 |
| --- | --- |
| [Biopython](%E5%BA%8F%E5%88%97%E4%B8%8E%E7%BB%93%E6%9E%84%E6%96%87%E4%BB%B6%E5%A4%84%E7%90%86/Biopython/README.md) | 提供读写、转换和处理生物序列、结构与注释的 Python 接口。可充当结构分析流程中的文件解析和数据组织层。 |
| [Biotite](%E5%BA%8F%E5%88%97%E4%B8%8E%E7%BB%93%E6%9E%84%E6%96%87%E4%BB%B6%E5%A4%84%E7%90%86/Biotite/README.md) | 为 Python 提供蛋白序列、分子结构和文件格式处理功能，可支持结构数据读写、选择与几何分析。 |
