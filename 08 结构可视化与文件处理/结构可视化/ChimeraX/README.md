# ChimeraX

显示、叠合和比较生物大分子三维结构。可用它检查局部构象、链间相对位置或实验密度与模型的对应关系。

## 输入与输出

- **输入**　PDB 或 mmCIF 的坐标、待显示的链或残基以及结构比对数据。
- **输出**　可交互三维视图、图像、会话文件，以及所选结构分析的数值结果。

## 接入条件

- **LLM 参与**　图形渲染和结构操作不需要 LLM。
- **运行条件**　需要适配操作系统的 ChimeraX 安装包。交互显示需要兼容的图形环境，特定扩展另有依赖。UCSF 对非商业和商业使用采用不同授权。商业用途需要单独取得许可。

叠合结果取决于所选参考原子或残基，保存选择与视图有助于重复比较。
